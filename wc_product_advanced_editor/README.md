# WC Product Advanced Editor

A specialized WooCommerce admin extension that replaces the standard product editor with a streamlined, AJAX-powered interface featuring rich-text editing and advanced typography controls.

## 🚀 Key Features

### 1. Unified Advanced Editor Interface
Access a dedicated editing screen under **WooCommerce > Product Advanced Editor** that allows you to manage core product data without the clutter of the standard WordPress editor.

### 2. Rich Text & Typography Controls
- **Line Height Control**: Precision line-height settings (1.0 to 2.5) for product descriptions.
- **Paragraph Spacing**: Control bottom margins (Small, Medium, Large, or None) for paragraphs and headings.
- **Font & Color**: Integrated color pickers and font size selectors for professional product storytelling.

### 3. Integrated Media Management
- **Featured Image Uploader**: Quick-change your main product image using the native WordPress Media Library.
- **Single Gallery Image**: Dedicated slot for a primary gallery image, ensuring consistent layout across product pages.
- **Auto-Replace Logic**: Replacing an image in the editor automatically updates the WooCommerce product data.

### 4. Streamlined Category Management
A persistent category checklist that allows you to re-assign product categories on the fly.

### 5. Admin Integration
Adds a convenient **"Advanced Edit"** link to the standard WooCommerce products list for instant access.

## 🛠 How to Use

1. Navigate to **WooCommerce > Product Advanced Editor**.
2. Select a product from the list by clicking **Advanced Edit**.
3. Use the rich text editor to format your description. Use the **Styles** dropdown in the editor toolbar to apply specific Line Height or Paragraph Spacing.
4. Click **Update Product** to save your changes via AJAX without refreshing the page.
